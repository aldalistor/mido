# أونكس المحاسبي — تطبيق سطح مكتب

واجهة أولية عربية لتطبيق محاسبي شامل مبني باستخدام Electron. التصميم يدعم اتجاه RTL ويستهدف Windows 10/11، مع بنية قابلة للتوسع إلى نظام محاسبي متكامل.

## التشغيل المحلي

```bash
npm install
npm start
```

## بناء نسخة Windows

```bash
npm run build:win
```

ستظهر ملفات التوزيع داخل مجلد `dist`.

## الوحدات المخطط لها

| الوحدة | نطاق العمل |
|---|---|
| لوحة التحكم | مؤشرات المبيعات والأرباح والمصروفات والسيولة، مع رسوم بيانية وملخص العمليات |
| المحاسبة العامة | دليل الحسابات، القيود اليومية، مراكز التكلفة، الفترات المالية، التسويات |
| المبيعات | عروض الأسعار، أوامر البيع، الفواتير، المرتجعات، التحصيلات، كشف العميل |
| المشتريات | طلبات الشراء، فواتير الموردين، المرتجعات، المدفوعات، كشف المورد |
| المخزون | الأصناف، المستودعات، التحويلات، الجرد، حركات المخزون، حد إعادة الطلب |
| التقارير | قائمة الدخل، الميزانية العمومية، التدفقات النقدية، ميزان المراجعة، أعمار الديون |
| الإدارة | المستخدمون، الصلاحيات، إعدادات الشركة، الضرائب، النسخ الاحتياطي والاستعادة |

## ملاحظات هندسية

النسخة الحالية هي Prototype بصري وتفاعلي يثبت تجربة الاستخدام واتجاه التصميم. المرحلة التالية تضيف قاعدة بيانات محلية، طبقة خدمات، المصادقة والصلاحيات، ثم ربط كل شاشة بالعمليات المحاسبية الفعلية مع سجل تدقيق ونسخ احتياطي.
