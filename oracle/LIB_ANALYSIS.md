# تحليل مكتبة Oracle Forms الإضافية

تمت مراجعة `Lib.zip` كمرجع legacy فقط. الملفات ذات الامتدادات `.fmx` و`.pll` و`.plx` و`.mmx` هي وحدات مترجمة من Oracle Forms، ولا يمكن استيرادها مباشرة داخل Electron. كما احتوى الأرشيف على ملفات Windows ثنائية مثل DLL وOCX وEXE؛ لذلك لم يتم تشغيلها أو تضمينها في حزمة التطبيق.

## المكونات المكتشفة

| الملف | المؤشر الوظيفي المستنتج | قرار إعادة البناء |
|---|---|---|
| `APSI009.fmx` | إدارة/حركة أصناف أو مستندات مرتبطة بـ `IAS_PURCHS_MAN`، مع بيانات المورد وحقول الهاتف والعنوان والحدود والتواريخ | إعادة بناء شاشة الجهات والموردين، مع سجل تدقيق وحقول عربية/إنجليزية |
| `APST015.fmx` | طلبات شراء تلقائية من خلال `Ias_Prqst_Auto_Mst` و`Ias_Prqst_Auto_Dtl` | إضافة دورة طلب الشراء: رأس الطلب، التفاصيل، الصنف، مركز التكلفة، المشروع، والحالة |
| `HRSS031.fmx` | نموذج موارد بشرية/إدخال عام يستعمل حقول تحقق وقوائم اختيار | يؤجل إلى مرحلة الموارد البشرية بعد تثبيت المحاسبة والمخزون |
| `YSPOS_MNU.mmx` | نقطة قائمة لنظام نقاط البيع، مع فواتير POS، طرق دفع نقدية وبطاقات وشيكات ومرتجعات | إضافة POS كوحدة مستقلة لاحقاً، وعدم خلطها مع القيود الأساسية في الإصدار الأول |
| `ERPSTPLIB.plx` و`YSERP_LIB.plx` | مكتبات مشتركة لإجراءات الواجهة والطباعة والتحقق | تحويل السلوك المطلوب إلى خدمات JavaScript صريحة، لا إلى تحميل PLX |
| `IASLIBSEC.plx` | منطق الصلاحيات والتحقق الأمني | تطبيقه عبر أدوار وصلاحيات محلية، مع تجزئة كلمات المرور وعدم تخزينها نصاً صريحاً |

## خارطة التحويل

يعتمد الإصدار الأول على نموذج محلي بسيط في Electron، مع الاحتفاظ بالتوافق المفاهيمي مع مخطط `oracle/001_security_and_fiscal_schema.sql`. تشمل الخطوة التالية استبدال `localStorage` بقاعدة SQLite، ثم إضافة الجداول المترابطة للفواتير وطلبات الشراء وحركات المخزون والقيود الناتجة عنها.

لا ينبغي نسخ DLL أو OCX أو EXE إلى حزمة التطبيق الجديدة دون مراجعة الترخيص ومصدر الملفات وتوافقها الأمني. كما يجب عدم استخدام أي كلمات مرور أو بيانات اتصال ظهرت داخل ملفات Forms القديمة؛ يجب تدويرها وإعادة إنشائها في بيئة آمنة.

## نتيجة المراجعة

يُستخدم `Lib.zip` الآن كمرجع لاستخراج أسماء الوحدات والحقول وسير العمل. أما التنفيذ الفعلي فيتم داخل كود Mido الحديث، بما يحافظ على وظائف النظام المطلوبة دون الاعتماد على Oracle Forms Runtime أو مكونات Windows القديمة.
