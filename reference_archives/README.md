# الأرشيفات المرجعية المحلية

تم حفظ النسخ الأصلية التالية محلياً داخل هذا المجلد:

| الملف | الاستخدام |
|---|---|
| `ERP_DBA.fmx` | مرجع شاشة/وحدة الإدارة وقاعدة البيانات القديمة |
| `Lib.zip` | مكتبات Oracle Forms وملفات DLL/OCX/PLX/MMX المرجعية |
| `Forms.zip` | مجموعة نماذج Oracle Forms المترجمة |

تم تسجيل البصمات الرقمية في `SHA256SUMS.txt`. هذه الملفات مستبعدة من Git بسبب حجمها وطبيعتها الثنائية، لكنها محفوظة في بيئة العمل المحلية. لا يتم تشغيل أي ملف ثنائي منها؛ تستخدم فقط للتحليل واستخراج المتطلبات.
